# Инструменты разработки project_med

## survey.py — опись кода для `_dev/КАРТА.md`

Что делает: читает исходники (`ast`, без импорта и запуска кода проекта) всех отслеживаемых
git файлов `*.py`, кроме `tests/`, и считает по каждому файлу строки, классы, функции,
функции без докстринга, без аннотации возврата, наличие описания модуля и внутренние
импорты; по пакетам — сводку и связи «кто кого импортирует».

Запуск (из корня проекта):

```bash
# Windows
.venv310/Scripts/python.exe -I -X utf8 _dev/tools/survey.py
# Linux
<venv>/bin/python -I -X utf8 _dev/tools/survey.py
```

Вывод: сводка по пакетам и связи — в консоль; подробности по файлам — в
`_dev/tmp/survey.json` (вне git). Ничего в проекте не меняет.

Замечания `pyflakes` к описи (по файлам):

```bash
.venv310/Scripts/python.exe -m pyflakes $(git ls-files '*.py' | grep -v '^tests/') \
    | sed -E 's/:[0-9]+:[0-9]+:? .*//' | sort | uniq -c | sort -rn
```

Создан 2026-10-25 (подробная карта).

## plan_refs.py — проверка ссылок плана в `_dev/КАРТА.md`

Что делает (только чтение): находит висящие ссылки в карте — на задачи (`Ф1.3.2`),
пункты `ОСТАЛОСЬ` (`ОСТ п. 4.1`), техдолг (`ТД-3`), идеи (`И-7`), требования
`Доработки.txt` (`Д5`), находки описи (`К2`); и открытые пункты `ОСТАЛОСЬ`, `ТЕХДОЛГ`,
`ИДЕИ`, которые план не упоминает (пункты с пометкой `[ИСПРАВЛЕНО]`, `[СНЯТО]`,
`[ПЕРЕНЕСЕНО]` — не нужны).

Запуск (из корня проекта):

```bash
.venv310/Scripts/python.exe -I -X utf8 _dev/tools/plan_refs.py
```

Вывод: число задач плана, число проблем и их список; «проблем: 0» — ссылки целы.
Проверен 2026-10-25 подложенными битыми ссылками (`Ф9.9`, `ОСТ п. 9.9`, `ТД-99`, `И-99`,
`Д99`, `К99` — все найдены). Запускать после каждой правки плана (Ф4.5).

## window_probe.py — главное окно без показа на временной базе

Окно создаётся, пилотный экран открывается, правка через черновики не пишет в БД до
«Сохранить», сохранение и закрытие с несохранённой правкой работают. Рабочие `.env`,
`config.msgpack`, `clinic.db`, журналы не трогаются (временная папка).

```bash
.venv310/Scripts/python.exe -X utf8 _dev/tools/window_probe.py   # Windows
<venv>/bin/python -X utf8 _dev/tools/window_probe.py             # Linux
```

Ожидаемо: все строки True, «Сохранено», в конце «+7 777». Основа будущего теста запуска
окна (`_dev/КАРТА.md` Ф2.1.8).

## real_db_copy_check.py — модели против копии рабочей базы

Копирует рабочую `clinic.db` (или путь аргументом) во временную папку, показывает
различия схемы, мигрирует копию, сверяет число записей. Рабочая база — только чтение.

```bash
.venv310/Scripts/python.exe -X utf8 _dev/tools/real_db_copy_check.py [путь к базе]
```

Ожидаемо: «различий после: 0», «изменения моделей без миграции: 0», записи совпадают.
Перед первым запуском новой версии на рабочей базе (Ф3.6) и после правок моделей.
Проверено 2026-10-25: до миграции — 1 различие (индекс заметок: рабочая база ещё без
`alembic_version`), после — 0; 20 пациентов, 47 приёмов, 21 фото, 495 заметок.

