# Карта тестов project_med

> Для разработчиков: какой модуль какими тестами проверяется, общие фикстуры, известные
> падения. Обновлять при добавлении, переносе и удалении тестов.
> Сформирована 2026-10-25 (по импортам в тестах); всего собирается 1777 тестов
> (с параметризацией), функций `test_*` — 1297.

## Запуск

```bash
# из корня проекта; _dev/ исключён в pytest.ini (norecursedirs)
# Linux:
QT_QPA_PLATFORM=offscreen /home/admin-rkc/Git/vive_vs_code/project_med/venv_project_med/bin/python \
    -m pytest -q -p no:cacheprovider
# Windows (Git Bash), 2026-10-25:
PYTHONIOENCODING=utf-8 QT_QPA_PLATFORM=offscreen .venv310/Scripts/python.exe \
    -m pytest -q -p no:cacheprovider
# один модуль:
... -m pytest -q -p no:cacheprovider tests/test_network
```

Перед прогоном: `printenv APP_CONFIG_PATH PROJECT_MED_ENV_DIR` должен быть пуст (иначе
перекроет временный конфиг — см. «Общие фикстуры»).
