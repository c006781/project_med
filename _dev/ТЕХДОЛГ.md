ТД-1. Яндекс.Диск: скачивание БД пишет прямо в рабочий файл (2026-10-21)
      app/network/ya_dop.py, yadisk_download_file; окно — SyncMixin._start_download.
      Как сейчас: скачивание идёт поверх открытого clinic.db.
      Чем грозит: оборвалась сеть посередине — рабочая база испорчена (половина файла),
      а открытое соединение SQLite видит подмену файла.
      Как исправить: скачать во временный файл рядом → проверить (размер/MD5 с Диска,
      открывается ли SQLite) → закрыть соединения с БД → резервная копия старой →
      os.replace → открыть заново.
      Решить: на Windows замена открытого файла (os.replace) падает, пока БД открыта —
      нужно закрывать соединения до замены; порядок закрытия/переоткрытия затрагивает
      окно и сервисы. Проверить на Windows («после RAD Studio»).
      Решение владельца 2026-10-25: исправлять, вариант А — временный файл → проверка
      (размер / MD5, открывается ли SQLite) → закрыть подключения → резервная копия → замена →
      открыть. Обрыв сети не должен портить рабочую базу; замена открытого файла на Windows —
      исправить (закрывать подключения до замены). Затирание локальных правок старой копией с
      Диска допустимо, но лучше проверять, что новее, и предупреждать (И-3). План — ПЛАН.md
      Ф1.5.1 (вместе с Ф2.1).

ТД-4. Автообновление: без проверки сертификата для приватного репозитория (2026-10-21)
      app/updater.py, UpdateDownloader.run.
      Как сейчас: verify=False, если задан GITHUB_TOKEN (комментарий: «иначе SSLEOFError в
      сборке PyInstaller»).
      Чем грозит: без проверки сертификата токен и скачиваемый exe можно
      перехватить/подменить (MITM) — запустится чужая программа.
      Как исправить: проверить на собранном exe verify=certifi.where() для приватного
      репозитория (публичный уже так); если SSLEOFError останется — разобраться с причиной
      (сертификаты в сборке, редирект на objects.githubusercontent.com), а не отключать
      проверку. Плюс — проверка хэша файла (ИДЕИ.md И-6).
      Решение владельца 2026-10-25: токен — только для тестирования; рабочие программы
      скачивают обновления по ссылке на открытый репозиторий (там сертификат уже проверяется,
      `certifi`). Добавить проверку файла релиза по хэшу (И-6). План — ПЛАН.md Ф1.5.4.

      базы — переоткрыть. План — ПЛАН.md Ф1.5.2.
