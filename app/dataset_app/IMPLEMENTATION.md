## 1. Поля — из `field_configs`, второй раз не описываются

Таблица соответствий — в описании `fields.py`. Главное:
* тексты заметок (`virtual` + `is_note`) — обычные поля набора: сохраняет их сервис;
* вычисляемое сервисом (`virtual` без `is_note`: ФИО у приёма, число фото) и ссылки на
  заметки (`updatable: False`) — `persistent=False`: читаются, не пишутся;
* вложенные списки DTO (`photos` у приёма) пропускаются — это подчинённый набор;
* ссылка на родителя (`references`) — из внешних ключей модели, кроме ссылок на заметки.

## 2. Источник поверх сервисов

`get_page_filtered` (условия, сортировка, окно, число строк — в БД), `get_by_id`,
`create/update/delete` + перечитывание строки (вернуть вычисленное сервисом). Сервис —
функцией при каждой операции (после смены БД — актуальный). `STARTSWITH` у сервисов нет —
отказ, а не молчаливая подмена на «содержит».

## 3. Мост к черновикам

Ядро о черновиках не знает (решение 2026-10-18) — мост живёт здесь. `post()` → черновик
(временный id < 0), удаление → пометка (строка видна зачёркнутой), показ — БД + черновики,
новые строки родителя — в первом окне. Изменения черновиков извне (другой экран,
отмена/повтор, сохранение) — наборы перечитываются (в правке — после неё); значки предков
(«изменены подчинённые») — `DataSet.touch`.

## 4. Найденное в коде программы (не в новом слое)

| | Что | Исправление |
|---|---|---|
| **APP1** | Поиск «без учёта регистра» (`ilike`) по кириллице учитывал регистр: встроенный `lower()` SQLite — только латиница («иван» не находил «Иванов»). Касается и нынешнего поиска в интерфейсе | `Database`: свои `lower`/`upper` для соединений SQLite (Юникод) |
| **APP2** | «Нет записи» у сервисов — разные исключения: `EntityNotFoundError` (наследник `LookupError`) и `PatientNotFoundError`/`AppointmentNotFoundError`… (не наследники) | источник распознаёт оба вида |
| **APP3** | ФИО пациента у приёма: `" ".join([фамилия, имя, отчество])` падал без отчества, ошибка проглатывалась — ФИО пустое (в настоящей базе пока у всех 20 пациентов отчество есть) | склеиваются только заполненные части |
