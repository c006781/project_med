# Пакет `drafts_qt` — таблицы Qt поверх черновиков

> Переносимый пакет: PySide6 + соседний пакет `drafts` (или `drafts` верхнего уровня).
> Код приложения не используется. Последнее обновление: 2026-10-16 (ветка `rework-drafts`).
> Ядро черновиков — [`../drafts/IMPLEMENTATION.md`](../drafts/IMPLEMENTATION.md).

| Файл | Назначение |
|---|---|
| [model.py](model.py) | `Column`, `DraftTableModel` — модель таблицы: показ с учётом черновиков, правка → черновик, цвета по статусу, реакция на события хранилища |
| [bridge.py](bridge.py) | `DraftsQtBridge` — события хранилища → сигналы Qt (значки строк и предков, замена id, «есть изменения») |

## 1. Как пользоваться

```python
from drafts_qt import Column, DraftTablePage

class PhotoSource:                       # любой источник: сервис, API, список
    def load(self, offset, limit, parent_id):
        return rows, total               # rows — словари с полем id

photos = DraftTablePage(store, 'photo', [Column('file_path', 'Файл')], PhotoSource(),
                        save_handler=lambda page: window.save(page.selected_nodes()),
                        requires_parent=True)
appointments.current_changed.connect(photos.set_parent)   # дети выбранной строки
```

## 2. Устройство и решения

* **Строки модели** — исходные данные страницы (из источника) + новые записи-черновики
  текущего родителя. Показ — `store.effective`, правка — `store.modify(..., original=исходное)`:
  вернули значение как было — черновик исчезает.
* **Модель подписана на хранилище**: изменения из другой таблицы/экрана сразу видны —
  значки предков, появление новых строк, исчезновение отменённых новых.
* **Новые строки учитываются множеством `_new_ids`**, а не знаком id: работает с любым
  генератором временных id (например, UUID).
* **После сохранения** модель просит перечитать страницу один раз на всю пачку событий
  (`QTimer.singleShot(0)`), id новой строки заменяется — страница сохраняет выделение.
* **Контекст родителя**: `set_parent(id)`; у таблицы детей (`requires_parent`) без родителя
  — пусто. «Добавить» недоступно, если по схеме типу нужен родитель, а он не задан (даже на
  экране «все записи»).
* **Ошибка источника строк** не ломает контекст: таблица пустая (видны только черновики),
  `load_failed(str)`, родитель выставлен — новые строки создаются под правильным родителем.
* **Цели сохранения**: `current_node()`, `selected_nodes()`, `page_nodes()` (выборка).

## 3. Ограничения

* Сортировка/фильтры по колонкам — на стороне источника (пока не реализованы в странице).
* Особые редакторы (дата, фото) — через `set_column_delegate`; встроенные редакторы Qt
  отдают свои типы (например, `QDate`) — их переводит `Column.from_edit`.
