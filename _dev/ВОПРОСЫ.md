### В-8. Автообновление на Linux — как (ТД-5, `ПЛАН.md` Ф1.5.5, М14) — 2026-10-31

Сейчас: архив `MedicalApp-linux.tar.gz` — исходники и скрипты; `install.sh` создаёт
`venv_project_med` и ставит пакеты из PyPI, `run.sh` запускает `main_gui_window.py`; данные
(`.env`, `config.msgpack`, база, фото, журналы) — в той же папке. Собранного бинарника нет;
автообновление на Linux останавливается на «только в собранном приложении».

* **А (рекомендация)** — программа скачивает `.tar.gz` (сверка SHA-256 уже есть),
  распаковывает во временную папку внутри папки программы, пишет `update.sh` и выходит;
  скрипт после выхода переносит прежний код в `backup_<версия>/`, кладёт новый (только пути
  кода по манифесту из `build_linux.sh`), при изменившемся `requirements.txt` — `pip install`,
  ошибка — откат из `backup_`, затем перезапуск. Данные и venv не трогаются. Правки: updater
  (признак установленного дистрибутива, безопасная распаковка, скрипт замены),
  `build_linux.sh` (манифест, метка), `run.sh` (переход в свою папку). Объём M.
* **Б** — собранный бинарник (PyInstaller / AppImage), замена одного файла, как на Windows.
  Риск: собранный на новом Ubuntu (новая glibc) может не запуститься на Astra Linux; Qt,
  FUSE для AppImage; существующие установки переводить вручную. Объём L.
* **В** — только уведомление: скачать `.tar.gz` со сверкой хеша и открыть папку,
  распаковывает пользователь. Объём S. Риск — при распаковке затереть данные, забыть
  `install.sh`.

Рекомендация — А (В можно первым шагом). Ещё: куда обычно ставится Linux-версия — в
домашнюю папку пользователя или в `/opt` от root (от этого зависят права на замену)?
Проверка — на Linux.

### В-15. `release.yml`, ручной запуск (`workflow_dispatch`) — 2026-10-31

Ввод `version` нигде не используется: `VERSION` получает имя ветки, тега у релиза нет (ОСТ
п. 1.10). Варианты: **А** — брать ввод как тег (`tag_name: ${{ inputs.version ||
github.ref_name }}` и в шагах `VERSION`); **Б** — убрать `workflow_dispatch` (выпуск только по
тегу `v*`). Рекомендация — Б (проще, один путь выпуска), если ручной запуск не нужен.
